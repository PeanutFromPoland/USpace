# Zrzuty dostępności KindSpot

Data: 2026-10-04. Rozdzielczość PNG: 824 × 1830. Widok logiczny: 412 × 915.

Zrzuty rzeczywistych aktualnych widgetów Fluttera, wykonane w kontrolowanym teście renderowania. Dane profilu są demonstracyjne. Nie są to zrzuty emulatora ani dowód pełnego audytu WCAG/TalkBack.

- 01-ustawienia-100.png: pełny panel ustawień; wysoki kontrast i ograniczenie animacji włączone, tekst 100%.
- 02-ustawienia-200-gora.png: ten sam panel przy tekście 200%. Etykieta dodatkowego powiększenia jest skrócona przez obecny interfejs; wymaga poprawy.
- 04-profil-100.png: profil przy tekście 100%.
- 05-profil-200-gora.png: górna część profilu przy tekście 200%.
- 06-profil-200-dol.png: przewinięty profil przy tekście 200%; widoczne wejście do ustawień i wylogowanie.

Do dokumentacji: porównanie profilu 100% i 200% oraz pełny panel ustawień 100%. Wersja 200% panelu dokumentuje również ograniczenie długości etykiety. Nie retuszowano ekranu w celu ukrycia ograniczeń.
